小江戸ゲーム部 YouTube管理ツール
プライバシーポリシー

最終更新：2026年11月27日

このページは、YouTube チャンネル「小江戸ゲーム部」の運営者が、自分のチャンネルを管理するためだけに使う小さなツール（Google Cloud のアプリ名「koedo-youtube-tools」）についての説明です。一般の方が使うサービスではありません。

使う情報

YouTube API サービスを通じて、運営者自身のチャンネルの次の情報だけを読み書きします。

  • 動画の題名・概要欄・サムネイル・公開予約の日時
  • 再生回数や視聴時間など、YouTube アナリティクスの数字

ほかの人のアカウントや個人情報は扱いません。

保存と共有

  • ログインの情報と集めた数字は、運営者のパソコンの中にだけ保存します。
  • 第三者に渡したり、売ったり、広告に使ったりしません。

許可の取り消し

このツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

関係する規約

このツールは YouTube API サービスを使っています。YouTube 利用規約とGoogle プライバシー ポリシーもご覧ください。
